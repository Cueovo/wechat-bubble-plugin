# 阶段 06：MVP 发布候选

## 目标

生成可复现、可安装、可升级、可降级、可卸载的原生 RootHide MVP `.deb`，只声明支持已完成全量回归的精确环境。

## 前置条件

- 阶段 00–05 全部通过。
- 支持矩阵、真机记录和性能结果完整。
- 发布构建工具链和源码 revision 已锁定。

## 发布范围

首个候选仅声明：

- iPhone 14 Pro Max（iPhone15,3）。
- iOS 16.5。
- 已记录精确版本的 Dopamine + ElleKit。
- 微信 8.0.60 的已验证精确 build。
- 原生 RootHide `.deb`。

其他设备可作为后续验证对象，不因为 CPU 或系统看似接近就自动列为支持。

## 实施步骤

1. 固定 package identifier、版本号和依赖声明。
2. 确认 Bundle Filter 只匹配微信主进程。
3. 由固定工具链从干净环境执行 Release 构建。
4. 检查 `iphoneos-arm64e` 包架构、RootHide scheme、动态依赖、资源和调试符号策略。
5. 生成 SHA-256，并绑定源码 tag/revision 和构建环境记录。
6. 执行全新安装、覆盖升级、降级、卸载和重新安装。
7. 执行最终功能、故障、安全模式、诊断和性能回归。
8. 检查产物不包含微信二进制、腾讯资源、私有头文件、设备凭据或测试日志。
9. 编写精确支持矩阵、已知限制和恢复/卸载步骤。
10. 未知微信版本保持默认关闭，不能为了发布临时放宽门控。

## 最终回归

- 冷启动、热启动、前后台切换。
- 单聊/群聊发送和接收文字。
- 单行、多行、长文本、Emoji、链接。
- Cell 快速复用和历史消息滚动。
- 深浅色切换、所有设置、恢复默认。
- 图片、语音、视频、文件、位置、转账保持原样。
- Unknown 版本、能力缺失、损坏偏好和安全模式。
- 安装、升级、降级、卸载。

## Release Gate

- [ ] RootHide 包架构和 scheme 正确，无需设备端 Convert。
- [ ] 所有必需依赖均明确且可满足。
- [ ] 支持矩阵中的唯一首发组合完成全量真机回归。
- [ ] 未知微信版本不启用气泡 Hook。
- [ ] 无启动崩溃、黑屏、崩溃循环和明显滚动退化。
- [ ] 非文字消息、点击、长按、布局和无障碍行为不变。
- [ ] 设置关闭或卸载后微信恢复默认。
- [ ] 诊断无账号与聊天内容。
- [ ] 包内容检查通过。
- [ ] 包哈希、源码 revision 和构建环境可以对应。

## 产物

- MVP 原生 RootHide Release `.deb`。
- SHA-256 校验值。
- 精确支持矩阵和已知限制。
- 安装、升级、降级、卸载与安全模式恢复说明。
- 完整真机验收记录。

## 完成门槛

Release Gate 全部通过后，MVP 才标记完成。后续支持新微信版本时，从阶段 02 建立新的版本适配事实，再走阶段 03、05、06 的回归，不直接复用白名单。
